## Über das Projekt
Das folgenden Projekt ist Teil des UX-Design Studiums an der IU Internationale Hochschule.

Ziel dieses 3-monatigen Creative Labs ist ein responsiver, persönlicher Webauftritt, welcher mithilfe von u.a. HTML und CSS erarbeitet wird. Dieser soll aus mindesten vier verlinkte Seiten oder einem vergleichbaren One-Pager mit mindestens vier Bereichen bestehen.

### Konzept
Für die Prüfungsleistung wird ein persönlicher Webauftritt für die Künstlerpersona [jen](https://www.youtube.com/@xunreachablee) in englisch erarbeitet. Diese soll stilistisch einem Album Booklet ähneln.

### Konzeptionsphase
In der ersten Phase dieser Prüfungsleistung wurde das Konzept erarbeitet. Dabei wurden sowohl Skizzen als auch erste Wireframes über [Figma](https://www.figma.com/design/ebjMQUW34owW2KuN6oWJDJ/Web-Programmierung?node-id=0-1&t=KXtZlQXSAG1KD8rG-1) zunächst für Desktop erstellt, die die ersten Ideen für den Webauftritt festhalten. Hier konnten die folgenden Seiten definiert werden:

### Seitenübersicht
| Bereich | Dateiname | Inhalt
|------|-----|-----|
| Startseite | `index.html` | Startpunkt und Übersicht aktueller Projekte  |
| Über Mich | `about.html` | Inhalte über die Künstlerpersona: Anfänge, Meilensteine, künftige Ziele |
| Persona | `persona.html` | Übersicht erstellter Illustrationen sowie Charakterreferenzen zur eigenen Erstellung |
| Musik | `music.html` | Übersicht aktueller Streaming Dienste und neuster Uploads |
| Videos | `video.html` | Persönliche Favoriten mit Angabe von Rolle innerhalb des kreativen Prozesses |
| Lyrics | `lyrics.html` | Übersicht erarbeiteter Lyrics |
| Equipment | `equipment.html` | Übersicht verwendeter Hard- und Software innerhalb des kreativen Prozesses |
| Kontakt | `contact.html` | Kontaktformular |
| Datenschutz | `policy.html` | Aufklärung bzgl. Erhebung von persönlichen Daten durch Kontaktformular |
| Error | `404.html` | Fehlerseite für nicht vorhandene Inhalte |
| Success | `success.html` | Proof of Concept für Nutzerfeedback, sobald Kontaktformular abgeschickt wurde |

Anschließend wurden die zu Blatt gebrachten Skizzen und digitale aufbereiteten Wireframes mit HTML und minimalmen CSS mit Visual Studio Code realisiert.

### Verwendete Technologien
- HTML
- CSS

### Offene To Do's
- Breakpoints definieren
- Geplante Seitenstruktur prüfen
- Navigationsmöglichkeiten definieren
- Benötigte Illustrationen sammeln
- Logo für Webauftritt erarbeiten & finalisieren
- Selbststudium bzgl. HTML, CSS, JavaScript und Accessibility im Web

## Erarbeitungsphase
In der zweiten Phase wurde das Konzept verfeinert. Dabei wurde relativ schnell klar, dass das geplante Konzept idealerweise mit Grid in Form eines Bento-Stils realisiert werden muss. Somit wurde sich vertieft mit dem Thema auseinandergesetzt und gleichermaßen das Thema "Dropdown" via CSS recherchiert.
